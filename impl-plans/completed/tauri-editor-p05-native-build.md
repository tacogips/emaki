## Intent

Produce the acceptance evidence that the native app binary builds with the production CSP and the embedded frontend, and that it starts. Also verify the repository hygiene rules.

## Non-goals

- Do not edit any source file.
- If `tauri.conf.json`, the capabilities or the frontend need a change, record a blocker that names the owning plan (P01 or P02) and the exact error. Do not fix it here.
- No bundling (`--no-bundle`) and no signing.
- No `npm install` beyond what P02 did.

## Steps

Run in `examples/tauri-editor` with `L=../../tmp/tauri-editor-20261110/tauri-editor-p05-native-build`.

1. **Version check (C6).**
   - Read `node_modules/@tauri-apps/api/package.json` `version`.
   - Run `(cd src-tauri && ~/.cargo/bin/cargo tree -p tauri --depth 0)`.
   - If `major.minor` differs, run `(cd src-tauri && ~/.cargo/bin/cargo update -p tauri --precise <latest patch of the api's major.minor>)`, recording the pre and post sha256 of `Cargo.lock`. If that is unresolvable (for example, plugin-dialog 2.7.0 requires a newer tauri), record a blocker.
2. **Build.** `npx tauri build --debug --no-bundle > $L/tauri-build.log 2>&1` with exit 0. Use a foreground timeout of at least 30 minutes.
   - The log must show `beforeBuildCommand` (`npm run build`) succeeding and the binary path.
   - Run `test -x src-tauri/target/debug/emaki-tauri-editor`.
3. **Production bundle check.** `rg -l "mockIPC|__tauriEditorMock" dist` must find no match.
4. **Launch evidence (best effort, owned lifecycle).** A one-off Node script under `$L/`:
   1. Write `$L/sample.ts`.
   2. `spawn` the debug binary with `[absolute $L/sample.ts]`.
   3. Wait 8 s, then record whether the child is still alive (`exitCode === null`).
   4. `kill('SIGTERM')`, wait for exit, and record stdout and stderr to `$L/launch.log`.

   The pass condition is that the process stays alive for 8 s without a panic in stderr. A visible window, the title and the WebGL2 rendering cannot be asserted headlessly. Record "GUI not observed" honestly and never claim `tauri dev` was observed. If the environment forbids GUI processes, record a blocked check with the error.
5. **Hygiene.** Run at the repository root:
   - `git diff --stat origin/main -- package.json package-lock.json > $L/root-deps.log` must be empty.
   - `git status --porcelain --ignored examples/tauri-editor > $L/status.log`: `src-tauri/target/` and `src-tauri/gen/` appear only with `!!` (ignored), and `src-tauri/Cargo.lock` and `package-lock.json` appear as `??` (not ignored).

## Pitfalls

- **Avoiding `tauri dev`.** Do not run `npm run tauri dev`. It is a long-lived dev server plus window with no owned end.
- **Never leave processes running.** Make sure the spawned binary is dead before returning, and check it with `pgrep -f emaki-tauri-editor` (no output).
- **Missing permission at runtime.** If a permission error appears at runtime in `launch.log`, report it as a P01 blocker with the exact permission id.

## Done when

- Steps 1-5 have recorded exit codes and complete logs.
- The binary exists.
- No mock code is in `dist`.
- Root dependencies are unchanged.
- The ignore rules are confirmed.
- The progress log records versions, any `Cargo.lock` hash change, the launch result (including the GUI-not-observed limitation) and blockers.
