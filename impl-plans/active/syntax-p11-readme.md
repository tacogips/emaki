## Changes

Rewrite the `## Languages` section and keep its existing first paragraph, which describes the line and span providers. Add these subsections in this order:

1. **Built-in languages.**
   - A table with columns `id | aliases | extensions/filenames`, generated by hand from the `languages` array in `src/language/registry.ts`. Read that file; do not invent entries.
   - Note that the build-output consoles and plain text are not highlighted.
2. **Selecting a language.** `resolveLanguage({ filename })` and `resolveLanguage({ fenceInfo })` examples, the precedence rule, and `undefined` for unknown input.
3. **Lazy loading.**
   - `const lang = await loadLanguage('rust')`, or a static `import { rustLanguage } from 'emaki/languages/rust'`.
   - Explain that bundlers split one chunk per language and that `import 'emaki'` alone pulls no languages.
4. **Embedded languages.**
   - `loadLanguage('markdown', { embedded: ['ts', 'python'] })` and `'all'`.
   - Unloaded fences render as plain strings.
   - HTML `<script>`/`<style>`, PHP, the templates, Vue and Svelte embed statically.
   - Known limitations: Svelte `}` in expressions, multi-line Vue opening tags, HTML state after a server block.
5. **Theme tags.**
   - List the 23 `standardTags`.
   - `createEditor(el, { language, theme: { tokens: { ...defaultTokenColors, keyword: [1, 0.5, 0, 1] } } })`.
   - JSON keeps its `json-*` tags.

Also update the `## Composition and diff` sentence or the export list where exports are enumerated, to mention `emaki/languages` and `emaki/languages/<id>`.
