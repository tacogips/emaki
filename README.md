# emaki

A canvas (WebGL2) code editor library for the browser.

- Virtualized rendering: only visible lines are tokenized, shaped and drawn.
- Line-embedded plugins: attach videos, animations, and other widgets to editor lines.
- Range formatting (color, background, weight, underline, glow) for character ranges and whole lines.

emaki was extracted from the [vactr](https://github.com/tacogips/vactr) live-coding editor.
The source is being staged in vactr and will be imported here.
